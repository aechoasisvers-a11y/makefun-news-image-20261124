A program that draws one image summing up Tuesday 24 November 2026's world news: six real stories across tech, the Gulf, Korea, Ukraine, the climate talks and Mexico, as a 1024x1024 PNG. Pure Python 3.13 standard library — it draws the whole poster with a hand-built 5x7 bitmap font and a minimal PNG encoder, so every headline is pixel-crisp and nothing is garbled.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
